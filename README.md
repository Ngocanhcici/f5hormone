# F5 Hormone - Hormone Health Coaching Platform

**F5 Hormone** là một nền tảng trực tuyến được thiết kế dành riêng cho phụ nữ trên 30 tuổi, giúp chăm sóc sức khỏe nội tiết thông qua thay đổi lối sống, dinh dưỡng và các phương pháp tự nhiên. Website được xây dựng bởi **Ngọc Anh** (IIN Certified Hormone Health Coach).

## 🚀 Tính năng chính

* **Hormone Quiz:** Bộ câu hỏi trắc nghiệm chuyên sâu giúp đánh giá sức khỏe nội tiết (đường huyết, stress, tiêu hóa, chu kỳ...).
* **Hệ thống Phân tích Kết quả:** Tự động tính điểm và đưa ra lời khuyên cá nhân hóa ngay lập tức.
* **Lead Generation:** Tích hợp thu thập thông tin khách hàng tiềm năng qua hệ thống ẩn.
* **Blog Kiến thức:** Khu vực chia sẻ bài viết về dinh dưỡng, yoga và lối sống cân bằng.
* **Giao diện Tối ưu:** Thiết kế sang trọng với bảng màu Sage/Cream, tương thích hoàn toàn trên Mobile và Desktop.

## 🛠 Công nghệ sử dụng

* **Frontend:** HTML5 & CSS3 (Custom Variables, Keyframe Animations).
* **Logic:** Vanilla JavaScript (Xử lý Single Page Application, Modal System, Quiz Logic).
* **Fonts:** Cormorant Garamond & Inter (via Google Fonts).
* **Data:** Tích hợp Google Forms để quản lý dữ liệu người dùng.

## ⚙️ Hướng dẫn cài đặt

1. Tải tệp `f5-hormone-optimized.html` về máy.
2. Đổi tên tệp thành `index.html` để có thể xuất bản lên GitHub Pages hoặc Netlify.
3. Mở tệp bằng bất kỳ trình duyệt web hiện đại nào.
